# Project Description

The Low Noise Amplifier (LNA) project focuses on designing a 4.5 GHz amplifier using the BFP620F transistor on Rogers RO4003C substrate.  
The aim is to achieve **maximum transducer gain** and ensure **unconditional stability** through proper matching networks.

Key topics: S-parameters, reflection coefficients, Smith chart, stability analysis, and microstrip design using NI AWR Microwave Office.
