# Methodology

1. **S-Parameter extraction** at 4.5 GHz.  
2. **Stability verification** using μ-test (μ > 1).  
3. **Input/output matching** using lumped elements.  
4. **Conversion to transmission lines** via Smith chart.  
5. **Microstrip design** using AWR’s TX-Line tool.  
6. **DC biasing** with VCE = 2 V, IC = 15 mA.  
7. **Simulation & tuning** to achieve gain ≈ 13 dB.  
8. **Fabrication & lab testing** for validation.
